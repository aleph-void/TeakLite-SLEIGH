# TeakLite-SLEIGH
##(WIP: complete in the Ghidra-Rare fork, see GHIDRA-RARE.md)
Ghidra processor defines for the DSi/3DS DSP's TeakLite ISA

Many thanks to Martin Korth for their documentation at [GBATEK](http://problemkaputt.de/gbatek.htm)
and wwylele for [Teakra](https://github.com/wwylele/teakra)

## Ghidra-Rare notes

This fork finishes the specification (original: [SachinVin/TeakLite-SLEIGH](https://github.com/SachinVin/TeakLite-SLEIGH),
MIT, one commit, 363 of 646 instruction constructors were `unimpl`) and verifies it against Teakra. Details, results and
credits: [GHIDRA-RARE.md](GHIDRA-RARE.md), [CREDITS.md](CREDITS.md). Prebuilt extension zips for Ghidra 12.1.3, 12.1.4 and
12.2 are on this repository's Releases page.

* Two languages: `teak:LE:16:default` (address registers are plain counters, readable decompiler output) and
  `teak:LE:16:modulo` (modulo, bit-reversed and Teak-style step addressing modelled in p-code). The context bit `AMOD`
  selects between them per region.
* Every one of Teakra's 443 instruction encodings is implemented, 65,536 / 65,536 opcode words decode like Teakra
  (validity and length) and the p-code agrees with Teakra on single instructions run from random states.
* A loader for the DSP1 firmware container is included.
* Stale claims in the original README fixed: it is no longer work in progress; the `utils/` scripts were what produced the old
  constructor list and are no longer used (the specification is generated by `tools/gen_teak.py`).

Original limitations (all of them were "not implemented yet") and where they stand:

| Limitation | State |
|---|---|
| 363 constructors `unimpl` (norm, swap, rep, mov variants, mul/mma family, ...) | fixed: all implemented |
| step/modulo/offset address generation not modelled (`StepAddress` todo) | fixed in the `modulo` language; the default language treats address registers as plain counters |
| accumulator saturation (`todo: saturate`) | fixed (SAT/SATA, LM) |
| `st0..st2`, `stt0..2`, `mod0..3`, `cfgi/j`, `ar/arp` as separate fake registers | fixed: composed from / decomposed into the flag bytes when read or written |
| `rep`, `bkrep` loops | `rep` is modelled (repeated delay-slot instruction); `bkrep` sets the loop stack but the implicit jump at the end address cannot be expressed in p-code (remains) |
| program-memory prefix `prpage` | register kept, program accesses use a 18-bit word address (remains) |
